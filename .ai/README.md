# `.ai/`: notas de trabalho para desenvolvimento assistido por IA

Estes arquivos são notas de especificação (spec-driven development) usadas ao construir o projeto com agentes de IA e podem estar defasados em relação ao código.

A documentação de referência, mantida em inglês, está em:

- [`docs/architecture.md`](../docs/architecture.md): camadas, módulos e fluxos
- [`docs/adr`](../docs/adr/README.md): decisões de arquitetura
- [`README.md`](../README.md): estado atual do projeto e quadro de progresso

As decisões que estavam em `.ai/decisions` foram migradas e atualizadas em `docs/adr`.
